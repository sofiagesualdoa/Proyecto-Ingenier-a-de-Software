# 🌟 Guía de Instalación - Sistema de Ventas EverGlow v1.0

¡Bienvenido a la guía oficial de instalación de **Sistema de Ventas EverGlow**! Sigue atentamente los pasos detallados a continuación para configurar e instalar el sistema correctamente en tu equipo.

---

## 📋 Requisitos Previos

Antes de comenzar, asegúrate de cumplir con los siguientes requisitos:
- **Espacio en Disco:** Se requieren al menos 24,5 MB de espacio libre.
- **Sistema Operativo:** Windows 10 o Windows 11 (32 bits / 64 bits).
- **Memoria RAM:** Mínimo 4 GB (Recomendado 8 GB)

---

## 🚀 Proceso de Instalación Paso a Paso

El asistente de instalación guiada te acompañará durante todo el proceso. Sigue estos pasos cronológicamente:

### Paso 1: Seleccione la Carpeta de Destino
Al ejecutar el instalador, la primera pantalla te solicitará elegir dónde debe instalarse el programa. Por defecto, se sugiere la ruta `E:\Program Files (x86)\Sistema de Ventas EverGlow`. Puedes usar el botón **Examinar...** para cambiarla o hacer clic en **Siguiente** para continuar.

![Paso 1 - Seleccione la Carpeta de Destino](image_45c21c.png)

### Paso 2: Seleccione las Tareas Adicionales
En la siguiente ventana, podrás elegir qué tareas adicionales deseas que se realicen durante la instalación. Puedes marcar la opción **Crear un acceso directo en el escritorio** para facilitar el ingreso al sistema. Luego, haz clic en **Siguiente**.

![Paso 2 - Seleccione las Tareas Adicionales](image_45c220.png)

### Paso 3: Listo para Instalar
El asistente mostrará un resumen de la configuración elegida (Carpeta de destino y Tareas adicionales). Revisa que todo esté correcto y haz clic en el botón **Instalar** para comenzar la transferencia de archivos.

![Paso 3 - Listo para Instalar](image_45c23b.png)

### Paso 4: Completando la instalación (Finalizar)
¡Felicidades! El programa ha completado la instalación con éxito en tu sistema. Puedes dejar marcada la casilla **Ejecutar Sistema de Ventas EverGlow** si deseas abrir la aplicación inmediatamente y presionar el botón **Finalizar** para salir del instalador.

![Paso 4 - Finalizar](image_45c242.png)

---

## 🛠️ Solución de Problemas Comunes (FAQ)

* **Error de permisos al instalar:** Asegúrate de ejecutar el archivo instalador haciendo clic derecho y seleccionando **Ejecutar como administrador**.
* **Falta de espacio:** Verifica tener la disponibilidad de espacio requerida (24,5 MB) en la unidad de disco seleccionada.
